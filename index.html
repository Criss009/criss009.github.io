Private workflow · Google Sheets integration

One master spreadsheet.
All your provider lists.

Master Sheet Cloud Sync is a private administration tool for organizing website-placement inventories from authorized Google Sheets. It helps keep provider records, prices, and changes aligned in a single master spreadsheet.

Not a public service. This project is operated for its owner's internal spreadsheet management. There is no public signup, account creation, or customer-facing dashboard.

How it works

Organized, scheduled, and access-controlled

01
Read authorized sources

Access configured Google Sheets that the connected Google account is permitted to open, without editing original provider lists.

02
Normalize and compare

Process website domains, provider names, guest-post and link-insertion prices, payment notes, and duplicate listings.

03
Update the master

Write consolidated records to the owner's master Google Sheet and keep synchronization logs for troubleshooting and audits.

Access and data

Why Google Sheets permission is requested

The Google Sheets OAuth permission is used to read authorized provider spreadsheets and update only the designated master spreadsheet. Sync jobs run on GitHub Actions. Authorization credentials are stored as GitHub Actions secrets, not in publicly published code.
