Data and privacy

Privacy Policy

Last updated: November 14, 2026

Master Sheet Cloud Sync is an internal-use tool. It does not offer public user registrations or accept Google sign-ins through this public website.

1. Purpose of the application

Master Sheet Cloud Sync is an automated workflow that reads authorized provider Google Sheets, normalizes website and pricing information, and updates a designated master Google spreadsheet. It also creates status and change reports to help the operator audit the synchronization.

2. Google user data accessed

When the operator grants Google Sheets access, the application may access the contents and metadata of spreadsheets available to that Google account and configured as synchronization sources or destinations. In normal operation this includes website URLs/domains, provider names, prices, currency, DA/DR/traffic fields, availability, payment terms, and related spreadsheet tab or row information. The OAuth scope used is https://www.googleapis.com/auth/spreadsheets, which grants spreadsheet read/write permission. The workflow is intended to read original provider sources without modifying them, and to write to the designated master spreadsheet.

3. How data is used

Data is used solely to consolidate listings, compare provider prices, flag missing or changed information, record advance-payment conditions, and operate or troubleshoot scheduled synchronization. Google user data is not used for targeted advertising or sold.

4. Data storage and service providers

Consolidated records, status details, and change history are stored in the operator's Google Sheets master file. GitHub Actions executes the synchronization code and may process source data transiently. GitHub Actions secrets store the Google OAuth credentials for the cloud workflow. Operational logs and report artifacts may contain limited spreadsheet identifiers, website domains, and sync errors; report artifacts are currently configured for retention of up to 14 days. Google and GitHub act as third-party infrastructure providers under their respective terms and privacy policies. This public website is hosted by GitHub Pages and does not contain the source spreadsheets or OAuth secrets.

5. Sharing and disclosure

Spreadsheet data is not made public by this website. The workflow processes data through Google's APIs and GitHub Actions as necessary to run the service. The operator may view or export the records in the private master spreadsheet. Data may be disclosed if legally required.

6. Security

The synchronization repository and master spreadsheet are intended to remain private and access-controlled. Credentials are stored as GitHub repository secrets, not in publicly hosted site files. Access is restricted by the operator's Google permissions. No internet service can guarantee absolute security.

7. Retention and deletion

Master records and change history are retained until the operator deletes them from the master spreadsheet or the connected services. Temporary GitHub Actions artifacts follow configured retention periods. The operator can revoke this application's Google access in Google Account security settings, remove its GitHub secret, or delete stored master records and logs.

8. Changes

This policy may be updated if the application changes its permissions, processing, storage, or sharing practices. The revision date at the top of this page will be updated accordingly.
